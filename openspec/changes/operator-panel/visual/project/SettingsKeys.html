4 · Deleting a key: a dialog with a plain button, as archiving a strategy

4a · "Delete key" was pressed on the Bybit card. Nothing is sent until "Delete key" is pressed in the dialog. Cancel has the focus when it opens.

Delete the Bybit key?

The key ending in 7Q2d is removed from this system. Bybit is no longer read or traded from here until a key is added again. Its history stays.

The server allows this only while every Bybit strategy is disabled and nothing is open on it.

4b · The server refused: the exchange is still in use. Each line says what is in the way and what to do. Only the kinds that exist are listed.

The Bybit key cannot be deleted yet. This is in the way:

  • 2 enabled strategies: Trend SOL, Breakout ETH. Disable them first.
  • Open position on: SOLUSDT. It has to be closed first.
  • 1 open allocation. It ends when its position is closed.
  • 1 live reservation: capital held for an order. Wait for it to finish, then try again.
  • 1 order being placed right now. Wait for it to finish, then try again.
